# Cartão de Perfil

Meu primeiro projeto de front-end, feito enquanto aprendo programação do zero.

## O que o projeto faz

- Mostra um cartão de perfil com foto, nome e frase de apresentação
- Um botão troca a frase a cada clique
- A lista de gostos é montada pelo JavaScript
- O layout se adapta ao celular

## Tecnologias usadas

- HTML
- CSS (Flexbox e @media)
- JavaScript (funções, condições, repetições e arrays)
- Git e GitHub

## O que aprendi

- Estruturar uma página com HTML
- Estilizar e organizar o layout com CSS
- Fazer a página reagir a cliques com JavaScript
- Guardar e versionar o código com Git

## Como ver o projeto

Baixe os arquivos e abra o `index.html` no navegador.
